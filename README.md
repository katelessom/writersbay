# Writers Bay

Локальная мастерская для планирования книг и рассказов: доска связей, досье персонажей, таймлайн, родословная, майнд-карта, трекер тайн и экспорт сессии в JSON.

Сайт: https://katelessom.github.io/writersbay/

Данные сохраняются в браузере пользователя через `localStorage`. Кнопка бэкапа скачивает проект в JSON-файл, который можно импортировать обратно.
